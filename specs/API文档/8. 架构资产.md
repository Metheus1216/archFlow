# 8\. 架构资产

### 8\.1 保存画布为资产



```HTTP
POST /api/v1/projects/:projectId/assets
Idempotency-Key: <uuid>
```



**请求体**：



```JSON
{ "name": "现状架构", "graph": { "nodes": [], "edges": [] } }
```



|字段|必填|约束|
|---|---|---|
|`name`|是|长度见 Zod（`AssetInput`），项目内可重名|
|`graph`|是|大小与深度见 `GraphInput`|

**错误**：

|HTTP|code|说明|
|---|---|---|
|413|`GRAPH_TOO_LARGE`|图序列化超过 `GRAPH_MAX_BYTES`|
|422|`GRAPH_INVALID`|图结构非法（`nodes` / `edges` 非数组、嵌套过深、`graph` 为 `null`）|



**响应 ****`201 Created`**：



```JSON
{ "id": "ast_1", "name": "现状架构", "createdAt": "2026-11-08T17:00:00+08:00", "updatedAt": "2026-11-08T17:00:00+08:00" }
```



### 8\.2 获取资产列表



```HTTP
GET /api/v1/projects/:projectId/assets?limit=20&cursor=xxx
```



**响应 ****`200 OK`**：分页结构，`items` 元素为 `{ id, name, createdAt, updatedAt }`（**不含图**）。



### 8\.3 获取资产详情（懒加载）



```HTTP
GET /api/v1/projects/:projectId/assets/:assetId?includeGraph=true
```



|参数|默认|说明|
|---|---|---|
|`includeGraph`|`true`|`false` 时只返回元信息（侧边栏预取用）。响应类型：`true` → `Asset`（含 `graph`）；`false` → `AssetMeta`（不含 `graph`）|



**响应 ****`200 OK`**：



```JSON
{
  "id": "ast_1",
  "name": "现状架构",
  "graph": { "nodes": [], "edges": [] },
  "createdAt": "2026-11-08T17:00:00+08:00",
  "updatedAt": "2026-11-08T17:00:00+08:00"
}
```



### 8\.4 更新资产



```HTTP
PATCH /api/v1/projects/:projectId/assets/:assetId
```



**请求体**（均可选）：



```JSON
{ "name": "现状架构 V2", "graph": { "nodes": [], "edges": [] } }
```



**响应 ****`200 OK`**：同 8\.3。

**错误**：同 8\.1（`413 GRAPH_TOO_LARGE` / `422 GRAPH_INVALID`）；另 `422 VALIDATION_FAILED`（`name`、`graph` 都未提供）。



> **原文档缺失**：资产只能「删了重建」。有了 `PATCH`，画布上「保存」按钮才能覆盖到已有资产。
> 
> 



### 8\.5 删除资产



```HTTP
DELETE /api/v1/projects/:projectId/assets/:assetId
```



**响应 ****`204 No Content`** \+ `X-Trace-Id` 响应头。
