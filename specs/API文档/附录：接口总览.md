# 接口总览与实施范围

除系统检查外，以下路径统一加 `/api/v1`。共 38 个方法/路径：第一版规划 36 个，密码重置暂缓 2 个。**当前 NestJS 尚无这些业务或系统路由**，本表不是实现进度表；进度见[待做清单](../待做清单.md)。

| 模块 | 方法   | 路径                                                        | 用途                       | 范围   |
| ---- | ------ | ----------------------------------------------------------- | -------------------------- | ------ |
| 认证 | POST   | `/auth/register`                                            | 注册                       | 第一版 |
| 认证 | POST   | `/auth/login`                                               | 登录                       | 第一版 |
| 认证 | POST   | `/auth/refresh`                                             | 刷新访问凭证               | 第一版 |
| 认证 | POST   | `/auth/logout`                                              | 退出                       | 第一版 |
| 认证 | GET    | `/auth/me`                                                  | 当前用户                   | 第一版 |
| 认证 | POST   | `/auth/password/forgot`                                     | 申请重置密码               | 暂缓   |
| 认证 | POST   | `/auth/password/reset`                                      | 执行重置密码               | 暂缓   |
| 项目 | GET    | `/projects`                                                 | 分页项目目录               | 第一版 |
| 项目 | POST   | `/projects`                                                 | 创建                       | 第一版 |
| 项目 | GET    | `/projects/:projectId`                                      | 详情                       | 第一版 |
| 项目 | PATCH  | `/projects/:projectId`                                      | 更新                       | 第一版 |
| 项目 | DELETE | `/projects/:projectId`                                      | 删除                       | 第一版 |
| 会话 | GET    | `/projects/:projectId/conversations`                        | 分页列表，具体数据组合待定 | 第一版 |
| 会话 | POST   | `/projects/:projectId/conversations`                        | 创建                       | 第一版 |
| 会话 | GET    | `/conversations/:conversationId`                            | 详情与草稿，不含消息       | 第一版 |
| 会话 | PATCH  | `/conversations/:conversationId`                            | 更新标题                   | 第一版 |
| 会话 | DELETE | `/conversations/:conversationId`                            | 删除                       | 第一版 |
| 会话 | GET    | `/conversations/:conversationId/messages`                   | 分页消息                   | 第一版 |
| 会话 | PUT    | `/conversations/:conversationId/draft`                      | 比较版本后保存草稿         | 第一版 |
| 会话 | POST   | `/conversations/:conversationId/fork`                       | 复制历史为独立会话         | 第一版 |
| 任务 | POST   | `/conversations/:conversationId/messages`                   | 保存消息并受理任务         | 第一版 |
| 任务 | GET    | `/runs/:runId/stream`                                       | 事件流与恢复               | 第一版 |
| 任务 | GET    | `/runs/:runId`                                              | 查询任务状态               | 第一版 |
| 任务 | POST   | `/runs/:runId/cancel`                                       | 请求取消                   | 第一版 |
| 卡片 | POST   | `/conversations/:conversationId/messages/:messageId/answer` | 回答并继续任务             | 第一版 |
| 文件 | POST   | `/projects/:projectId/files`                                | 上传                       | 第一版 |
| 文件 | GET    | `/projects/:projectId/files`                                | 列表                       | 第一版 |
| 文件 | GET    | `/projects/:projectId/files/status`                         | 批量状态                   | 第一版 |
| 文件 | GET    | `/files/:fileId`                                            | 详情                       | 第一版 |
| 文件 | GET    | `/files/:fileId/content`                                    | 鉴权下载                   | 第一版 |
| 文件 | DELETE | `/projects/:projectId/files/:fileId`                        | 删除                       | 第一版 |
| 资产 | GET    | `/projects/:projectId/assets`                               | 列表                       | 第一版 |
| 资产 | POST   | `/projects/:projectId/assets`                               | 保存命名图                 | 第一版 |
| 资产 | GET    | `/projects/:projectId/assets/:assetId`                      | 详情与按需图数据           | 第一版 |
| 资产 | PATCH  | `/projects/:projectId/assets/:assetId`                      | 更新                       | 第一版 |
| 资产 | DELETE | `/projects/:projectId/assets/:assetId`                      | 删除                       | 第一版 |
| 系统 | GET    | `/health`（根路径）                                         | 进程检查                   | 第一版 |
| 系统 | GET    | `/ready`（根路径）                                          | 依赖检查                   | 第一版 |
