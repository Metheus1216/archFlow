# 附录：接口总览

|模块|方法|路径|说明|
|---|---|---|---|
|Auth|POST|`/auth/register`|注册|
||POST|`/auth/login`|登录|
||POST|`/auth/refresh`|刷新 token|
||POST|`/auth/logout`|登出|
||GET|`/auth/me`|当前用户|
||POST|`/auth/password/forgot`|申请重置|
||POST|`/auth/password/reset`|执行重置|
|Project|GET|`/projects`|项目树（分页聚合）|
||POST|`/projects`|新建|
||GET|`/projects/:projectId`|详情|
||PATCH|`/projects/:projectId`|更新|
||DELETE|`/projects/:projectId`|删除|
|Conversation|GET|`/projects/:projectId/conversations`|列表（分页）|
||POST|`/projects/:projectId/conversations`|新建|
||GET|`/conversations/:conversationId`|详情（不含消息）|
||PATCH|`/conversations/:conversationId`|更新标题|
||DELETE|`/conversations/:conversationId`|删除|
||GET|`/conversations/:conversationId/messages`|消息（分页）|
||PUT|`/conversations/:conversationId/draft`|保存草稿（乐观锁）|
||POST|`/conversations/:conversationId/fork`|分叉|
|Run|POST|`/conversations/:conversationId/messages`|发送消息（受理）|
||GET|`/runs/:runId/stream`|SSE 取流|
||GET|`/runs/:runId`|查状态|
||POST|`/runs/:runId/cancel`|取消|
|Card|POST|`/conversations/:conversationId/messages/:messageId/answer`|提交卡片回答|
|File|POST|`/projects/:projectId/files`|上传|
||GET|`/projects/:projectId/files`|列表|
||GET|`/projects/:projectId/files/status`|批量状态|
||GET|`/files/:fileId`|详情|
||GET|`/files/:fileId/content`|下载（二进制）|
||DELETE|`/projects/:projectId/files/:fileId`|删除|
|Asset|GET|`/projects/:projectId/assets`|列表|
||POST|`/projects/:projectId/assets`|保存画布|
||GET|`/projects/:projectId/assets/:assetId`|详情（懒加载）|
||PATCH|`/projects/:projectId/assets/:assetId`|更新|
||DELETE|`/projects/:projectId/assets/:assetId`|删除|
|System|GET|`/health`|存活检查|
||GET|`/ready`|就绪检查|
