# API 文档入口

> 复查日期：2026-11-13。这些文档描述目标接口，当前 NestJS 业务接口和系统探针均未实现。前端 `/api/mock` 是单独的开发模拟接口，不能用它的行为替代本文。
> 字段、格式、长度和枚举以 [`packages/shared/src/schemas/`](../../packages/shared/src/schemas/) 为准。文档说明请求顺序、权限、状态和错误处理；发现代码与目标有差异时，见[待确认问题](../待确认问题.md)。

## 推荐阅读顺序

1. [全局规范](./1.%20全局.md)：前缀、认证、响应、错误、分页、重复请求与安全。
2. [接入说明](./11.%20接入说明.md)：前端如何按顺序调用接口。
3. [接口总览](./附录：接口总览.md)：查路径与第一版/后续范围。
4. 按业务阅读模块，再从[数据定义索引](./10.%20数据模型（Zod）.md)定位实际 Schema。

| -------- | --------------------------------------------- | ---------------------------------------------- |

## 当前实现前必须关注的差异

- 图没有坐标字段，尚不能满足保存拖拽位置的要求。
- 暂停数据的具体类型、恢复输入和进程重启处理尚未完整定义。
- 现有过滤器普通校验失败返回 400，目标规范是 422；成功出口校验与 traceId 尚未补齐。
- 错误响应 `data` 为 `null`，不能从错误数据中读取活跃任务或最新版本；冲突后查询正常资源。
- 数据库没有软删除/恢复能力；不承诺“删除后 30 天恢复”。

对应任务与验证要求见[待做清单](../待做清单.md)。
