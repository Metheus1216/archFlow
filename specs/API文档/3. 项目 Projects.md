# 3\. 项目 Projects

### 3\.1 获取项目树（首屏聚合）



```HTTP
GET /api/v1/projects?limit=20&cursor=xxx
```



**描述**：一次性拉取侧边栏所需骨架。**项目列表分页；`files` / `assets` / `conversations` 条数见 `ProjectNode`**，超出走子接口。



**查询参数**：



|参数|默认|说明|
|---|---|---|
|`limit`|20|项目数，最大 50|
|`cursor`|—|分页游标|



**响应 ****`200 OK`**：



```JSON
{
  "items": [
    {
      "id": "prj_1",
      "name": "电商中台",
      "description": "订单域重构",
      "createdAt": "2026-11-01T10:00:00+08:00",
      "updatedAt": "2026-11-08T16:00:00+08:00",
      "lastActiveConversationId": "cnv_9",
      "files": [
        { "id": "fil_1", "fileName": "需求.md", "fileType": "text", "status": "ready",      "createdAt": "2026-11-02T09:00:00+08:00" },
        { "id": "fil_2", "fileName": "tops.png", "fileType": "image", "status": "processing", "createdAt": "2026-11-08T15:00:00+08:00" }
      ],
      "assets": [
        { "id": "ast_1", "name": "现状架构", "createdAt": "2026-11-05T11:00:00+08:00" }
      ],
      "conversations": [
        { "id": "cnv_9", "title": "订单服务拆分", "updatedAt": "2026-11-08T16:00:00+08:00" }
      ]
    }
  ],
  "nextCursor": null,
  "hasMore": false
}
```



|字段|说明|
|---|---|
|`lastActiveConversationId`|**服务端维护**的最近活跃会话 id。前端直接用它加载，**不再自己遍历找 ****`updatedAt`**** 最大者**（分页后会失效）|
|`files[].status`|含 `failed` / `stored`（pdf/docx 仅上传），见 §1\.10|



> **不变式**：`files` / `assets` / `conversations` 均为**最近更新优先**，条数见 `ProjectNode`。

### 3\.2 新建项目



```HTTP
POST /api/v1/projects
Idempotency-Key: <uuid>
```



**请求体**：



```JSON
{ "name": "电商中台", "description": "订单域重构" }
```



|字段|必填|约束|
|---|---|---|
|`name`|是|长度见 Zod（`CreateProjectInput`），允许重名|
|`description`|否|长度见 Zod（`CreateProjectInput`）|



**响应 ****`201 Created`**：



```JSON
{ "id": "prj_1", "name": "电商中台", "description": "订单域重构", "createdAt": "2026-11-08T16:50:30+08:00", "updatedAt": "2026-11-08T16:50:30+08:00" }
```



### 3\.3 获取项目详情



```HTTP
GET /api/v1/projects/:projectId
```



**响应 ****`200 OK`**：同 3\.2 响应结构（不含嵌套数组）。



### 3\.4 更新项目



```HTTP
PATCH /api/v1/projects/:projectId
```



**请求体**（字段均可选，只传要改的）：



```JSON
{ "name": "电商中台 V2", "description": "订单域重构二期" }
```



**响应 ****`200 OK`**：同 3\.2。



### 3\.5 删除项目



```HTTP
DELETE /api/v1/projects/:projectId
```



**响应 ****`204 No Content`**，响应头带 `X-Trace-Id`。



> 级联：项目下的会话、资产、文件一并软删除（30 天内可恢复，待确认）。
