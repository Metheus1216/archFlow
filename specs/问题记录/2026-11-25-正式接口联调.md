# 2026-11-25 正式接口联调

联调使用本机隔离的 PostgreSQL 16（pgvector 0.8.7）、Redis 和 MinIO。NestJS 从 `/api/v1` 提供业务接口。模型请求由本机 OpenAI 兼容测试服务返回可重复的结果。AC1 至 AC7 在该环境下通过，Chrome 主流程发出 0 条 Mock 请求。

| 模块 | 联调结果 |
| --- | --- |
| AC1 账号与项目 | 健康和就绪探针、所有者隔离通过。Chrome 可注册并从空态创建项目和会话，刷新时静默轮转 Cookie 并打开原会话。双标签页退出状态一致，重登后可继续使用项目 |
| AC2 流式对话 | Chrome 显示逐段正文，选项回答后在原助手消息继续。正式接口验证阶段事件、正文分段落库、按编号无重复续传、重复提交卡片答案的幂等性。取消后保留已保存的图和草稿版本，可继续发送 |
| AC2 重启与历史回放 | 在流式任务处理中重启 API，已写入的正文保留，任务标记失败且会话可接受新任务。查询旧任务时从数据库回放该次的架构图，当前草稿保留新版 |
| AC3 生成、解释和修改图 | Chrome 可追问后画图、修改图、按指定历史图解释。指代不清时先追问。按项目文档修改商品查询并解释时保留订单链路。解释超时后复用临时图，只提交一次。缺资料时保留原稿，提示解释未完成 |
| AC4 画布草稿 | Chrome 中拖拽和自动布局都能在刷新后恢复。旧标签页保存返回 `409 DRAFT_VERSION_CONFLICT`，点击「读取最新画布」后显示先保存的位置。手动保存与助手改图冲突时保留手动新版，重试可在该版上继续改图 |
| AC5 资产 | 正式接口验证幂等保存。Chrome 中资产立即出现在侧栏。修改草稿再刷新后，资产预览仍显示保存时的图和坐标 |
| AC6 历史恢复与分支 | Chrome 可恢复旧图并查看原有消息，也可从历史开启带有当时架构图的新会话。正式接口验证两个会话分别保存草稿 |
| AC7 项目资料 | Chrome 上传文本后显示可引用，刷新后仍可查看原文引用。正式接口验证 Markdown 与 TXT 的 pgvector 原文引用和资料范围隔离。资料缺失、正在解析、解析失败或仅存储时均提示对应状态，引用区为空。图片读取后可进入解析完成状态，PDF 与 DOCX 仅存储 |
