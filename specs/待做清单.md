> 状态符号：⬜ 未开始 / 🟡 进行中 / ✅ 完成 / ⏸ 暂缓。

## 0. 当前状态

**已具备**

- 数据库：9 张表实体 + 初始迁移，真实 PostgreSQL 验证通过；`pnpm db:migrate` 可重复执行。
- API 地基：DataSource / Redis / MinIO 接线，全局 `ZodValidationPipe`、统一异常外壳与 `X-Trace-Id`，未知路由返回 404 外壳。
- 契约：common / auth / project / knowledge / asset / conversation / agent / sse / system / mock 已导出；运行态、HITL 中断与图结构已在 P0-01 / P0-13 定稿。
- 本地工作台具备注册、登录、静默续期和按账号保存的项目、会话。Mock 消息接口返回运行句柄，客户端消费 SSE，支持分段文字、卡片恢复、重连与取消。默认使用固定响应，可配置 `ARCHFLOW_PREVIEW_AGENT` 预览模型正文流。演示步骤见 [接手说明](Agent架构讨论交接.md#5-本地体验与正式验收)。
- Agent 核心已有整句规则、可选意图样例匹配、一次 LLM 判断和改写、两种执行策略、澄清恢复与图补丁。代码契约见 `packages/shared/src/schemas/orchestration.schema.ts`，通过 `pnpm test` 可运行 `packages/agent/tests/engine.test.ts`。
- `AgentRunService` 已接 TypeORM。受理与单活跃 run、同 ID 续跑、草稿版本检查、项目资料隔离已通过数据库集成用例。验证使用启用 pgvector 的隔离 PostgreSQL 兼容实例，命令为在设置测试库 `ARCHFLOW_TEST_DATABASE_URL` 后运行 `pnpm test apps/api/tests/agent-run.integration.test.ts`。
- 文档：`mvp.md`、`数据流.md`、`API文档/`、`表设计.md`、`架构规划.md`、P0 实施记录。

**主要缺口**

- 正式端到端链路仍需接入 NestJS 鉴权、项目和会话 HTTP 接口，以及基于数据库的 SSE 回放。Web 正式接入进度见 P0-19。
- 文档入库、正式环境联调和真实模型效果评测仍待验收。
- 画布渲染可用于预览结果。自动保存、资产与历史分叉属于正式 API 联调范围。

> 证据：迁移、API 启动与 404 外壳见 [后端 P0 基础设施落地](./问题记录/2026-11-11-后端P0基础设施落地.md)。

## 1. 优先级定义

- **P0**：阻塞 MVP 主链路；不做就无法端到端跑通。
- **P1**：不阻塞主链路，但直接影响质量、安全或可评估性。
- **P2**：post-MVP 扩展；有明确触发条件再做。

## 6. 明确不在清单内

## 8. 完成定义

一项任务标记 `✅` 前，至少满足：

1. 契约先改 `packages/shared`，类型检查通过；涉及数据库的补迁移。
2. 有对应测试或可复现的验收步骤（写清命令），不能只写“已实现”。
3. 错误路径有明确返回码，不泄露堆栈 / SQL / 内部路径。
4. 关键路径有 traceId 和日志。
5. 文档中的契约与代码一致；行为变了就同步 `API文档` / `表设计` / `数据流`。
6. 本地演示可用 Mock，并注明已验证的行为。勾选正式接入的验收项时，以真 API 的验证结果为准。
