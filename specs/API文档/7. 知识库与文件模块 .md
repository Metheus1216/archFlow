# 7\. 知识库与文件模块 

### 7\.1 上传文档



```HTTP
POST /api/v1/projects/:projectId/files
Content-Type: multipart/form-data
```



**表单字段**：`file`



**允许类型（白名单）**：



|扩展名|`fileType`|解析能力|
|---|---|---|
|`.md`、`.txt`、`.markdown`|`text`|解析，可被 Agent 引用|
|`.png`、`.jpg`、`.jpeg`、`.webp`|`image`|解析，可被 Agent 引用|
|`.pdf`|`pdf`|**仅上传存储，不解析**|
|`.docx`|`docx`|**仅上传存储，不解析**|
|其他|—|一律 `415` / `FILE_TYPE_UNSUPPORTED`|

> **解析能力矩阵**：`text` / `image` 上传后进入 `processing`，完成后 `ready` 或 `failed`；`pdf` / `docx` 上传后直接为 `stored`，不解析、不可被 Agent 引用。前端据此展示「暂不支持解析」。



> 原文的「\.md, \.txt, \.png, \.jpg **等**」无法实现，已改为明确白名单。
> 
> 内容真实性校验（magic bytes）与病毒扫描属**待定项**，本版只校验扩展名 \+ 大小。
> 
> 



**限制**：单文件 ≤ **20MB**（超出 `413` / `FILE_TOO_LARGE`）；单项目文件数上限待定。



**响应 ****`201 Created`**：



```JSON
{
  "id": "fil_1",
  "fileName": "需求.md",
  "fileType": "text",
  "mimeType": "text/markdown",
  "sizeBytes": 20480,
  "status": "processing",
  "errorMessage": null,
  "createdAt": "2026-11-08T16:50:30+08:00"
}
```



> **不再返回 ****`url`**。下载统一走鉴权下载接口（见 7\.4），不暴露存储地址，也不存在「URL 多久过期」的问题。
> 
>

### 7\.3 获取文件详情 / 批量查状态



```HTTP
GET /api/v1/files/:fileId
```



**响应 ****`200 OK`**：同 7\.1 响应。



**批量查状态**（前端轮询专用，轻量）：



```HTTP
GET /api/v1/projects/:projectId/files/status?ids=fil_1,fil_2,fil_3
```



**响应 ****`200 OK`**：



```JSON
{
  "items": [
    { "id": "fil_1", "status": "ready",      "errorMessage": null },
    { "id": "fil_2", "status": "processing", "errorMessage": null },
    { "id": "fil_3", "status": "failed",     "errorMessage": "文件编码无法识别" },
    { "id": "fil_4", "status": "stored",     "errorMessage": null }
  ]
}
```



> **这是对「****`processing → ready`**** 前端怎么知道」的解法**：上传后前端轮询此接口（建议 2s 起步指数退避，上限 60s），比让前端轮询全量列表便宜得多。
>
> `stored`（pdf/docx）是终态，无需轮询；`ids` 条数上限见 `FileIdsQuery`。
> 
> 若未来文件数量大，再考虑 `GET /projects/:id/events` 的 SSE 推送通道。
> 
> 



### 7\.4 下载文件（鉴权下载）



```HTTP
GET /api/v1/files/:fileId/content
Authorization: Bearer <accessToken>
Range: bytes=0-1023            ← 可选
```



**响应 ****`200 OK`**** / ****`206 Partial Content`**（二进制，**不走统一外壳**）：



```HTTP
Content-Type: text/markdown
Content-Disposition: attachment; filename*=UTF-8''%E9%9C%80%E6%B1%82.md
Content-Length: 20480
Accept-Ranges: bytes
ETag: "a1b2c3"
X-Trace-Id: 7f3a1c9e4b2d
```



**关于「为什么 15 分钟过期」（回应你的疑问）**：



- 15 分钟是指**对象存储的签名 URL**（S3/OSS Presigned URL）的有效期，属于「前端拿 URL 直连存储」方案。

- 现在选的是**鉴权下载**：文件字节经由你的 API 服务转发，请求带 `Authorization` 头校验。

- 所以**没有 URL 过期概念** —— 权限有效期就是 AccessToken 的有效期（15 分钟自动续），不需要额外设计失效逻辑。

- **代价**：文件流量走应用服务器，占带宽。补偿措施：支持 `Range`（断点续传/视频拖动）、加 `ETag`（浏览器缓存）、上游加 CDN 时可再评估。
