# 运行中断与图契约落地（P0-01 / P0-13）

> 日期：2026-11-12
> 范围：`packages/shared`、`packages/db`、`apps/web/lib/mock-graph.ts`、测试与文档
> 结论：契约、实体与迁移脚本已落地；迁移待真实 PostgreSQL 复跑（本机 Docker/WSL 起不来）。

## 背景

- 表设计、API 文档与数据流已经描述了 `waiting_input`、`runs.metadata`、`agent_states.version`、SSE `interrupt`，但 Zod 与实体没跟上，属于“文档先行、代码落后”。
- 图结构一直是 `looseObject` + `unknown[]`，Agent 生成、画布渲染、资产存储没有共同契约，继续往下做会返工。

## 改了什么

### 1. 运行态与中断（P0-01）

- `RunStatus` 增加 `waiting_input`（非终态）。
- 新增 `InterruptKind` / `Interrupt`：`interruptId`、`kind`、`node`、`payload`、`expiresAt`。
- `SseFrame` 增加 `interrupt` 帧（字段与 `Interrupt` 一致），`run-start` 增加 `resume?: boolean`。
- `runs` 表增加 `metadata JSONB`，实体同步；`agent_states` 增加 `version INTEGER NOT NULL DEFAULT 0`。
- 新增迁移 `20261112000000-RunMetadataAndAgentStateVersion`，并注册到 `data-source.ts`。

### 2. 图契约（P0-13）

- 新增 `NodeType`（7 类：client / gateway / auth / service / worker / database / cache）。
- 新增严格结构：`GraphNode`（id / type / label / description?）、`GraphEdge`（id / source / target / label?）、`Graph`（nodes / edges / version?）。
- `GraphInput` 增加引用校验：重复节点 / 边 id、悬空边、自环；规模上限 200 节点 / 400 边；保留 512KB 与深度兜底。
- 会话草稿与消息快照暂用 `LooseGraph` 读取旧 mock 图，P0-16 切换画布时统一迁到 `Graph`。

### 3. 测试与文档

- 接入 Vitest 4（Node 20 兼容），`pnpm test` 可跑；新增 9 条契约用例。
- API 7.6 去掉 TBD，写明图结构、NodeType、校验与错误码；`10. 数据模型` 补充引用完整性与节点上限。
- `10. 数据模型（Zod）` 顶部标注增量范围，避免继续按旧快照实现（全量收敛见待做清单 D-01）。
