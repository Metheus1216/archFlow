# 10. 数据定义索引（Zod）

数据字段的唯一维护位置是 [`packages/shared/src/schemas/`](../../packages/shared/src/schemas/)。TypeScript 类型由 Zod 推导，本文不保存整份代码副本。

## 文件与用途

| 源文件                                                                             | 主要定义                                                     | 相关接口                       |
| ---------------------------------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------ |
| [common.schema.ts](../../packages/shared/src/schemas/common.schema.ts)             | ID、时间、状态枚举、图、图请求校验、错误字段、分页与响应包装 | 全局、草稿、资产               |
| [auth.schema.ts](../../packages/shared/src/schemas/auth.schema.ts)                 | 用户、邮箱、注册/登录/退出输入与凭证结果                     | 认证                           |
| [project.schema.ts](../../packages/shared/src/schemas/project.schema.ts)           | 项目、侧栏简要信息、项目目录聚合、创建/更新输入              | 项目                           |
| [conversation.schema.ts](../../packages/shared/src/schemas/conversation.schema.ts) | 会话、消息、卡片、引用、用量、草稿、发消息与复制输入         | 会话、卡片                     |
| [knowledge.schema.ts](../../packages/shared/src/schemas/knowledge.schema.ts)       | 文件基本信息、文件列表和批量状态查询                         | 文件                           |
| [asset.schema.ts](../../packages/shared/src/schemas/asset.schema.ts)               | 资产基本信息/图、保存更新和详情查询                          | 架构资产                       |
| [agent.schema.ts](../../packages/shared/src/schemas/agent.schema.ts)               | 生成任务、暂停记录、执行阶段、受理结果和取消结果             | Agent                          |
| [sse.schema.ts](../../packages/shared/src/schemas/sse.schema.ts)                   | 流式事件 `SseFrame`、结束标记和 JSON 事件解析                | 任务流                         |
| [system.schema.ts](../../packages/shared/src/schemas/system.schema.ts)             | 健康检查响应                                                 | 系统接口                       |
| [mock.schema.ts](../../packages/shared/src/schemas/mock.schema.ts)                 | 开发期模拟数据与旧坐标图                                     | 仅 `/api/mock`，不属于真实接口 |

错误码常量位于 [error-codes.ts](../../packages/shared/src/constants/error-codes.ts)，公共导出入口位于 [index.ts](../../packages/shared/src/index.ts)。

## 已有定义与未完成行为

- `GraphNode`、`GraphEdge`、`Graph` 和 `GraphInput` 已定义。结构和引用校验不等于画布交互或图生成已经完成。
- `RunStatus.waiting_input`、`Interrupt`、SSE `interrupt` 和 `run-start.resume` 已定义。暂停 `payload` 目前只限制为对象，具体交互数据仍要细化。
- 会话 `draftGraph` 与消息 `graphSnapshot` 仍使用 `LooseGraph` 兼容旧模拟图，切换在 P0-16 处理；新请求使用 `GraphInput`。
- 现有 `Graph` 不包含用户布局，新增字段须先讨论并修改 Zod，不能绕过严格校验。
- 密码重置有输入定义，但暂不实现接口；会话分页、条件状态和运行元数据尚需按具体任务补定义。

## 修改规则

先改共享定义，再改前后端及必要迁移。字段语义、调用顺序、状态与错误响应同步修改对应 API 文档；长度、格式和枚举不在文档中另维护一份数值规则。

原手抄版本保留在[历史快照](../archive/2026-11-11-数据模型Zod快照.md)，仅供追溯，已停止维护。当前没有生成 OpenAPI 的脚本，不能把“已有 Zod”描述成“文档与接口自动同步”。
