# 2\. 认证

## 2\.1 注册



```HTTP
POST /api/v1/auth/register
Idempotency-Key: <uuid>
```



**请求体**：



```JSON
{ "username": "林杉", "email": "a@b.com", "password": "123456" }
```



|字段|类型|必填|约束|
|---|---|---|---|
|`username`|string|是|长度见 `RegisterInput`（先 trim 再计长）|
|`email`|string|是|见 `Email`：**trim + 转小写后**校验与去重|
|`password`|string|是|长度见 `RegisterInput`（强度策略待定）|



**响应 ****`201 Created`**（`data`）：



```HTTP
Set-Cookie: refreshToken=rt_9f1c2d...; HttpOnly; Secure; SameSite=Lax; Path=/api/v1/auth; Max-Age=2592000
```

```JSON
{
  "accessToken": "eyJhbGciOi...",
  "tokenType": "Bearer",
  "expiresIn": 900,
  "user": {
    "id": "usr_1a2b3c",
    "username": "林杉",
    "email": "a@b.com",
    "avatarUrl": null,
    "createdAt": "2026-11-08T16:50:30+08:00"
  }
}
```

> `refreshToken` 只通过 `Set-Cookie` 下发，响应体不含该字段。



**错误**：



|HTTP|code|
|---|---|
|409|`EMAIL_TAKEN` 邮箱已被注册|
|422|`VALIDATION_FAILED` 参数校验失败|



## 2\.2 登录



```HTTP
POST /api/v1/auth/login
```



**请求体**：



```JSON
{ "email": "a@b.com", "password": "123456" }
```



**响应 ****`200 OK`**：结构同 2\.1（含 `tokenType`、`expiresIn`），同样通过 `Set-Cookie` 下发 refreshToken。

> 邮箱按 `Email` 归一化（trim + 小写）后再比对；`A@B.com` 与 `a@b.com` 视为同一账号。



**错误**：



|HTTP|code|说明|
|---|---|---|
|401|`INVALID_CREDENTIALS`|邮箱或密码错误（**不区分**到底是哪个错，防账号枚举）|



## 2\.3 刷新 Token



```HTTP
POST /api/v1/auth/refresh
```



**请求体**：无。服务端从 `httpOnly` Cookie 读取 refreshToken。



**响应 ****`200 OK`**（响应体只含 accessToken；refreshToken 通过轮转后的 `Set-Cookie` 下发）：



```HTTP
Set-Cookie: refreshToken=rt_新值...; HttpOnly; Secure; SameSite=Lax; Path=/api/v1/auth; Max-Age=2592000
```



```JSON
{ "accessToken": "eyJ...", "tokenType": "Bearer", "expiresIn": 900 }
```



**错误**：`401` / `REFRESH_INVALID`（已失效，前端清态跳登录）。



> **一次性轮转**：每次刷新都换新 refreshToken，旧的立即作废。并发刷新会导致后到的那个 401，前端必须做刷新去重（见 §1\.2）。
> 
> 



## 2\.4 登出



```HTTP
POST /api/v1/auth/logout
Authorization: Bearer <accessToken>
```



**请求体**（可选；refreshToken 由 Cookie 携带，不在 body 中）：



```JSON
{ "allDevices": false }
```



**响应 ****`204 No Content`**，响应头带 `X-Trace-Id`。



`allDevices: true` 时吊销该用户全部 refreshToken。



## 2\.5 获取当前用户



```HTTP
GET /api/v1/auth/me
```



**响应 ****`200 OK`**：`data` 直接是 `User` 对象（同 2\.1 的 `user` 字段），不再包一层 `{ user }`。



> 首屏用，避免前端只能从注册/登录响应里缓存用户信息。
